# Engine torque

This table describes the engine: each cell is torque in Nm at one RPM and throttle opening.

## Load a table

1. Click **Import engine table…** and choose a CSV, XLSX or DSS file.
2. If several tables are listed, choose the intended table. A throttle map in percent cannot be used here.
3. Check the breakpoints and the curve before clicking **Next: torque request →**.

## Read the map

| You see | It is |
|---|---|
| Rows | Engine speed in RPM. |
| Columns | Throttle opening in percent. |
| Coloured cells | Torque in Nm; blue is the low end, red the high end of this map. |
| RPM picker above the curve | The row drawn in the chart. |

Use measured data for the engine and configuration you are working on. The startup table is a synthetic example.
