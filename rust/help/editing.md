# Edit a map

The coloured cells are editable. The colour bar shows their range; colour describes value, not whether a value is safe.

| Do this | Get that |
|---|---|
| Click a cell | Choose the starting cell for paste and table tools. Its border is outlined. |
| Drag a value | Increase or decrease it. |
| Double-click a value | Type a replacement. |
| Paste spreadsheet cells | Replace a rectangular block starting at the chosen cell. Invalid blocks leave the table unchanged. |
| **Table tools** → **Copy table** | Copy the whole map, including breakpoints. |

Tables show every row without a separate vertical scrollbar. If the map is taller than the window, scroll the page; wide maps scroll horizontally.

## Table tools

1. Choose a cell, row header or column header.
2. Open **Table tools**, choose **Apply to**, then **Fill**, **Add offset**, **Multiply** or **Interpolate endpoints**.
3. Set **Value** when needed and click **Apply**.

Interpolation keeps both endpoints and uses the numerical breakpoints. Input maps can add or remove rows and columns. Result breakpoints are changed in **Calculation**.

| Key | Action |
|---|---|
| Command-Z | Undo. |
| Command-Shift-Z | Redo. |
| Command-V | Paste at the chosen cell. |

Use Control instead of Command on Windows and Linux.
