# Build a throttle map

You need an engine torque table in Nm and a torque request in Nm. The result is a throttle target in percent.

1. Open **Engine torque** and click **Import engine table…**. Check the RPM and throttle breakpoints.
2. Open **Torque request**. Click **Import request…**, or open **Generate a torque request** and click **Generate request**.
3. Open **Calculation**, check the output breakpoints and click **Calculate ETV map**. The result opens under **ETV map**.
4. Inspect the coloured cells and the RPM curves. Review the marked cells before applying corrections.
5. Open **Export**, choose a format and save the map.

Use **Save as…** to keep the inputs and result together as a project. A calculated map needs dyno validation before riding.
