# Export

Export saves the result as RPM × grip position → throttle target (%).

1. Choose **CSV**, **Excel (.xlsx)** or **Mectronik (.dss)**.
2. For DSS, check the table and axis paths against the ECU's destination table.
3. Click **Export ETV map…** and choose where to save the file.

If inputs have changed, return to **Calculation** and recalculate first.

Check the destination table, axes and units before using the export. OpenETV does not send data to an ECU. Validate the map on a dyno before riding.
